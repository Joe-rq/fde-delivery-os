# 第六课 · FDE 求职/作品集/创业路径

> **来源**：FDE 共学营第一期。本页只记录受课程启发的方法论骨架与项目映射，**不复制课程正文、PPT 或讲义**。课程原始内容受版权保护，公开改编许可未确认，详见 [来源登记](../06-Sources/来源登记.md)。
>
> **覆盖**：PPT 62 页 + 完整课程文稿

## 核心论点

一个可验收的交付案例是硬通货——向左重构成「简历四信号 + 作品集」敲开岗位，向右重构成「Solo FDE 三段式商业闭环」接出第一单；无论哪条路，单干都靠 Echo-Delta 搭伙与节点网络，而非全才孤军。

## 方法论地图

### 项目完成后两条路

- **要点**：结营项目是一张门票，主动选求职（岗位画像/简历/作品集/面试）或独立（付费诊断/目标交付/长期陪跑），不随缘；两条路共用同一条证据链。
- **框架/术语**：项目完成后两条路、求职四件套、Solo FDE 三段式
- **项目对应**：[个人FDE定位](../00-Map/个人FDE定位.md)、[FDE交付闭环](../00-Map/FDE交付闭环.md)（证据链止于复用）
- **Gap**：⚠️缺口——个人定位有「我是谁」，缺「交付完成后往哪走」的决策分支。
- **吸收建议**：在 00-Map 新增「交付完成后两条路」决策页，把十步闭环出口接到求职四件套与 Solo 三段式。

### FDE 角色分工：Echo / Delta / Solo

- **要点**：FDE = Forward Deployed Engineer（前沿部署，非前端部署）；最简小队 = 一个 Echo（行业专家：发现问题/管关系/翻译需求）+ 一个 Delta（工程师：原型/打磨/生产交付）；Solo 是一人担两者；AI 是业务语言与机器语言间的「本体翻译器」。
- **框架/术语**：Echo / Delta / Solo FDE、最简 FDE 小队、Ontology 本体翻译
- **项目对应**：[FDE能力地图](../00-Map/FDE能力地图与成长路线.md)（八维能力 + Echo/Delta/Solo 角色分工）
- **Gap**：🔧补强——已补角色分工表（见能力地图），把八维标注到对应角色。
- **吸收建议**：已落实；求职或搭伙前用角色分工判断自己位置。

### 识别真岗位（五道压力测试）

- **要点**：国内 title 不统一，判断看职责（是否进现场 + 是否对结果负责）；五道压力测试全过才是真 FDE：薪资含提成、写代码占一半以上、有产品反哺通道、签单前进场、有需求纠偏权限。
- **框架/术语**：真假 FDE 五道压力测试、薪资光谱、Title 通胀
- **项目对应**：[求职准备](../07-Portfolio/求职准备.md)（五道测试反识别表）、[FDE资源矩阵](../08-Resources/FDE资源矩阵.md)
- **Gap**：🔧补强——已补五道压力测试反识别表（见求职准备）。
- **吸收建议**：已落实。

### 简历四信号

- **要点**：招聘方找四个信号——端到端负责（Ownership）、客户接触面（Customer Exposure）、生产环境真上了（Production）、可量化结果（Measurable Outcomes）；项目描述公式：动词+你构建的东西+客户上下文+量化结果，用「我」不用「我们」；没商业数字也能量化三类：测试集指标/效率指标/边界指标。
- **框架/术语**：简历四信号、项目描述公式、五区骨架、项目经历五段式
- **项目对应**：[求职准备](../07-Portfolio/求职准备.md)（四信号对照表 + 五段式）、[公开发布说明](../07-Portfolio/公开发布说明.md)
- **Gap**：🔧补强——已补四信号对照表和项目经历五段式（见求职准备）。
- **吸收建议**：已落实；旧版笔记把四信号误猜为发现/定界/Eval/采用，现更正为上述四个。

### 作品集（黄金结构 / 三种颗粒度 / 脱敏）

- **要点**：作品集不是 GitHub star 数，是「模糊需求→可验收结果」的完整故事；案例黄金结构 5 项（业务背景/需求边界/方案选型/Eval结果/失败复盘，失败复盘是可信度证据）；三种颗粒度（社媒长文/GitHub README/一页PDF）；脱敏红线三件套（客户名抽象/数据换模拟/截图打码）。
- **框架/术语**：案例黄金结构 5 项、三种颗粒度、脱敏红线三件套、客户逐级缩小冷启动
- **项目对应**：[作品集路线](../07-Portfolio/作品集路线.md)（8 项证据 + 三种颗粒度 + 脱敏红线）
- **Gap**：🔧补强——已补三种颗粒度对照表 + 脱敏红线 checklist + 冷启动阶梯。
- **吸收建议**：已落实。

### 面试考判断（拆解面 / 四项练习）

- **要点**：FDE 面试考「面对从没见过的问题你怎么思考」，不是算法；拆解面（Decomposition）是核心，给模糊真实题第一步是提问不是画架构；Re-engineering 轮（陌生代码+错误输出）、Learning 轮（现场学新 DSL）；OpenAI 挂人最多在 Evals Engineering；四项日常练习（口述 Scoping/陌生 repo 先猜后验/读新工具文档讲心智模型/故事库）。
- **框架/术语**：拆解面 Decomposition、Re-engineering 轮、Learning 轮、Evals Engineering、四项日常练习
- **项目对应**：[求职准备](../07-Portfolio/求职准备.md)（面试三轮 + 四项练习）、[SOW-Spec-Demo证据链](../01-Methods/SOW-Spec-Demo证据链.md)、[Eval与验收](../01-Methods/Eval与验收.md)
- **Gap**：🔧补强——已补面试转化层（拆解面/Re-engineering/Learning/Evals Engineering/四项练习）。
- **吸收建议**：已落实；项目 SOW→拆解面起手式，Eval→Evals Engineering 弹药。

### Solo FDE 商业闭环（三段式 / 诊断收费）

- **要点**：三段式——付费审计（卖带 ROI 的诊断报告，不接「我想上 AI」）/ 目标交付（客户下目标，FDE 全权打法，目标层验收靠约定测试集）/ 持续陪跑（按月订阅）；诊断必须收费四理由（卖结果不卖调研/可抵扣设计/算损失账/客户质量过滤）；签约前锁四件事（范围/Baseline/验收人/付款）；价格四层世界（电商模板 200-500 元/中小企业 5-15 万/机构 70-1100 万/驻场 ¥6365 万（PPT 原值，经 L6 62页 OCR 复核））。
- **框架/术语**：Solo FDE 三段式、诊断收费四理由、可抵扣设计、签约四件事、四个价格世界
- **项目对应**：[Solo FDE 商业闭环](../07-Portfolio/Solo-FDE商业闭环.md)、[复用飞轮](../01-Methods/复用飞轮.md)、[项目机会筛选](../01-Methods/项目机会筛选.md)
- **Gap**：🔧补强——已补 Solo 三段式 + 签约四件套 + 价格四层世界（见 Solo-FDE商业闭环）。
- **吸收建议**：已落实；本课最大缺口已补。

### E-A-D 协作栈与 DeltaEcho 网络

- **要点**：E-A-D 协作栈——Echo（行业认知+信任）/ Agent（AI 翻译层）/ Delta（工程核心）；DeltaEcho 网络三节点（Echo 手里有真场景/Delta 工程交付/Solo FDE 扎根行业）；四条纽带（技术准入/工具引力/利益引力/品牌引力）。
- **框架/术语**：E-A-D 协作栈、DeltaEcho 网络、三节点、四纽带
- **项目对应**：[Skill与Harness](../05-Engineering/Skill与Harness.md)（Harness 概念）
- **Gap**：⚠️缺口——项目是单人方法论，无协作网络层；属组织创新概念，不应写成项目既定方法。
- **吸收建议**：先在 06-Sources 把 DeltaEcho/E-A-D 标 C 级受限启发；正文确认前不写成既定方法。

## 溯源补遗（2026-08-08 对照文字稿后补录）

- **考官观察七件事**（原笔记只收四项练习，补考官视角）：①先澄清再动手 ②切出自然边界（大问题拆可独立验证模块）③覆盖边缘与失败路径 ④显式表达假设 ⑤为取舍给理由 ⑥高压下表达连贯 ⑦始终想着最终用户。对应 [求职准备](../07-Portfolio/求职准备.md) 面试层。
- **独立 FDE 三坑**：①全才幻觉（承认能力边界，找 Echo/Delta 搭档）②所有员工陷阱（AI 让每项变快却让人同时接下所有岗位，须限并发、标准化、留高价值判断）③三个月荒废（上线后无人维护无预算而停用，须交付前验真实 ROI 并设负责人/评测/迭代机制）。
- **脱敏红线第四件·授权边界**：除客户名抽象/数据换模拟/截图打码外，**只有在客户明确书面授权后**才展示可识别名称、数据或聊天内容——补全 [作品集路线](../07-Portfolio/作品集路线.md) 原「三件套」漏录的授权维度。
- **作品集案例六部分**（原笔记压缩成 5 项）：业务背景 / 需求边界 / 方案取舍 / **交付过程** / 业务结果 / 失败复盘，补回「交付过程」。
