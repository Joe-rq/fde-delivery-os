# 来源与证据策略

## 来源层级

| 代码 | 类型 | 用法 |
|---|---|---|
| P | 个人实践 | 用日志、测试、截图、运行记录支持 |
| O | 官方/一手 | 用于事实、定义、产品行为和公开规则 |
| R | 研究/高质量开源 | 用于方法比较和外部框架 |
| C | 课程 | 用于理解讲师方法，不自动视为通用事实 |
| N | 社区笔记/二手材料 | 用于发现线索，关键主张需回查 |

## 主张状态

- `Confirmed`：有直接证据；
- `Inferred`：基于证据的合理推断；
- `Hypothesis`：待项目验证；
- `Opinion`：作者或讲师观点；
- `Disputed`：存在冲突证据；
- `Stale`：可能已过时。

## 许可证

- MIT、Apache-2.0 等代码许可证不自动覆盖文章正文和品牌素材。
- CC BY 需要署名；CC BY-SA 的改编内容通常需保持相同许可。
- 非商业阅读/分享材料不得复制进商业模板或付费内容。
- 未知许可：只保留短摘要、事实性描述和链接。

## 入库决策

优先更新既有主题，只有满足以下至少一项才新建主题：

- 形成新的关键判断；
- 引入独立的执行流程；
- 需要单独维护的评测或模板；
- 是重要个人项目证据；
- 与既有观点存在需要长期追踪的冲突。
