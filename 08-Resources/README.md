# FDE 资源导航

这里不做“收藏夹”，而是回答三个问题：当前项目阶段该读什么、读完要产出什么、哪些结论能成为交付证据。

## 四层资源

| 层级 | 用途 | 使用规则 |
|---|---|---|
| 个人实践 P | 验证方法是否真能交付 | 必须带样本、运行记录、失败与边界 |
| 官方一手 O | 定义角色、架构、标准与官方实践 | 优先支撑可核验事实，记录日期和版本 |
| 高质量研究/开源 R | 比较方法、参考工程实现 | 先看许可，再决定摘要、改编还是仅引用 |
| 课程/社区 C/N | 获取经验判断和案例线索 | 不把讲师数字或学员笔记当作已验证事实 |

## 按项目阶段选资源

| 当前任务 | 先读 | 读完产出 |
|---|---|---|
| 理解 FDE 与交付责任 | OpenAI FDE、Palantir Architecture、OpenFDE | 个人定位和交付闭环 |
| 判断项目是否值得做 | FDE Guidance Book、私有实践复盘 | 问题定义、五张地图、机会评分 |
| 选 Workflow 还是 Agent | Anthropic Building Effective Agents、12-Factor Agents | 备选架构、复杂度理由和 fallback |
| 连接企业系统 | MCP、OpenAI Agent Guide、Palantir Ontology | 工具合同、权限边界和业务语义 |
| 设计 Eval 和验收 | Anthropic Agent Evals、OpenAI Evals、Phoenix | 数据集、评分器、错误分类、发布门 |
| 进入生产 | NIST AI RMF、OWASP GenAI、Harness Engineering | 威胁模型、审计、回滚、Runbook |
| 形成作品 | FDE Roadmaps、本仓库案例页 | 可演示系统 + 可复算证据 + 边界声明 |

## 入库门槛

一份资料只有在至少形成一项新资产时才进入主库：

- 改变了一项项目判断；
- 补充了检查清单或模板；
- 增加了一类失败样本或 Eval；
- 形成可复用的 Skill、连接器或发布门；
- 为已有主张提供了更高等级证据。

否则，只保留在 [来源登记](../06-Sources/来源登记.md) 或待验证队列中。
