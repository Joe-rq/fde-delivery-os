# FDE 共学营 · 课程笔记索引

> 本目录记录受「FDE 共学营第一期」启发的方法论骨架，**不复制课程正文/PPT/讲义**。课程原始内容受版权保护，公开改编许可未确认；本目录只做方法论映射和 gap 标注，详见 [来源登记](../06-Sources/来源登记.md)。

## 为什么单独成目录

课程是本仓库方法体系的重要启发源。逐课做方法论骨架映射，目的是：把课程视角与项目已有资产对照，诚实标注「已覆盖 / 补强 / 缺口」，让读者一眼看清项目哪里扎实、哪里受了课程启发、哪里还是 open gap。

## 使用方式

- 读项目正文前先看对应课的笔记，了解课程视角和该主题的完整骨架。
- gap 标注三级：✅已覆盖（项目已有且更细）/ 🔧补强（本轮已补）/ ⚠️缺口（建议未实施）。
- 📝建议未实施的项是 open backlog，需单独评估是否新建文件或属个人策略。
