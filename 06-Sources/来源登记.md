## 许可核验摘要

核验日期：2026-08-01。

- XDash 指南没有独立 `LICENSE` 文件；README 明确允许免费阅读与非商业分享，商业使用需书面许可。
- OpenFDE 站点标示 `CC BY-SA · MIT`，但公开页未在每项内容旁明确文件级范围，因此只登记、不复制。
- ChatDemo 的 LICENSE 明确区分代码 MIT 与长文档 CC BY-SA 4.0。
- Awesome FDE Roadmap 与 OpenAI Knowledge Retrieval 的 LICENSE 为 MIT。
- Forward Deployed Engineer Roadmap 使用自定义 `ZERO PUBLIC LICENSE 1.0`，不把它等同于标准 SPDX/OSI 许可证。
- 12-Factor Agents 明确区分正文/图像的 CC BY-SA 4.0 与代码的 Apache-2.0。
- Phoenix 使用 Elastic License 2.0，不将它记为 MIT/Apache 式宽松许可。

## 使用纪律

- 具体事实优先使用 P/O；R/C 用于比较方法，不自动成为事实。
- 数字进入公开案例时必须带样本、口径、证据强度和核验日期。
- 来源链接最近一次集中核验日期为 2026-08-01；外链状态记录在 [公开发布说明](../07-Portfolio/公开发布说明.md)。
- 来源许可与内容许可分别判断；“公开可访问”不等于“可复制、改编或再授权”。
