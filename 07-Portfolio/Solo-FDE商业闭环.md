# Solo FDE 商业闭环

把交付方法论升级为可独立运营的商业模式。受课程启发，用项目自己的话重述；详见 [来源登记](../06-Sources/来源登记.md)。

## 三段式

| 阶段 | 卖什么 | 验收 |
|---|---|---|
| 付费审计 | 带 ROI 测算的诊断报告（不接「我想上 AI」） | 报告交付 |
| 目标交付 | 客户下目标，FDE 全权负责打法 | 双方约定的测试集达标 |
| 持续陪跑 | 按月订阅，系统迭代 + 带练员工 | 持续运行 |

以 [复用飞轮](../01-Methods/复用飞轮.md) 为资产化底座——每单交付后做资产抽取，同类第二单人天省三成。

## 诊断为什么必须收费

1. 卖结果不卖过程：交付的是审计报告，别叫「调研费」。
2. 可抵扣设计：诊断费全额抵扣交付款，改变老板心理账户。
3. 算损失账：几千块报告买的是不踩几十万的坑。
4. 客户质量过滤器：不愿出诊断费的是尾款拖欠高危户。

注意：这里的「付费诊断」是售前商业产品，与 [进场诊断 Playbook](../02-Playbooks/进场诊断Playbook.md)（交付期发现技术）不是一回事。

## 签约前锁四件事

比技术能不能做更决定赚不赚钱：

- 范围
- Baseline
- 验收人
- 付款条件

## 价格四层世界

| 层 | 区间 | 形态 |
|---|---|---|
| 电商模板 | 200-500 元 | 标准化 |
| 中小企业（主战场） | 5-15 万 | 目标交付 |
| 机构采购 | 70-1100 万 | 项目制 |
| 大型驻场 | ¥6365 万 | 长期 |

独立 FDE 已明码标价（月费/年框）。

> 区间为课程讲师经验值（非市场统计）；驻场 ¥6365 万为 L6 PPT 原值（2026-08-08 经 62 页 OCR 复核）。

## 三个坑

- 全才幻觉：没有 Echo 的 Delta 进不了场。
- 所有员工陷阱：AI 让你膨胀接活，然后把自己累死。
- 三个月荒废：无人维护的一锤子买卖。

> 本页是个人商业模式策略，非通用交付方法。客户分层和线索 qualification 见 [项目机会筛选](../01-Methods/项目机会筛选.md)。
