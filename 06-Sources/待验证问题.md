# 待验证问题

## 证据与许可

- 受限课程启发内容能否逐项证明为独立原创表达，或取得必要公开许可？
- 如何提供可复算的最小沙盒证据包，同时不复制课程材料？
- 哪些外链会随岗位页、产品文档或仓库状态变化，需要定期重验？

## 项目

- 启衡 **FDE 课程沙盒 PoC / 合成数据** 中哪些模式可以迁移，哪些只是练习设定？
- HIS 问题诊断作为 `project-candidate / discovery-needed`，哪类问题最适合第一轮合规 Discovery？
- 表单、SOP、规则、搜索与 Agent 在问题诊断中的增量价值怎样比较？
- 如何在不接触敏感内容的情况下建立授权、脱敏的评测样本？
- 真实脱敏案例（field-case）已示范“把真实交付脱敏成公开证据”的模式；授权、可独立复算的样本仍待建立。

## 方法

- 五张地图中，哪张对项目风险的预测力最高？
- 机会评分阈值是否能在多个合规项目中稳定校准？
- 什么时候该使用 Agent，什么时候规则 + Workflow 更优？
- 怎样将采用、复用和反馈指标写进不制造单边风险的 SOW？

## Skills

- `fde-opportunity-diagnosis` 是否能减少过早进入方案阶段？
- `fde-eval-acceptance` 能否稳定区分目标、验收线与业务愿景？
- `fde-knowledge-ingest` 能否阻止重复页面和未核实数字扩散？
- 3 个 Skills 在不同模型和运行时中的 eval 通过率是多少？
