# 项目机会筛选

## 客户分层（PSF 三关之前的战略预筛）

判断单个机会之前，先看客户本身值不值得进场。两个维度——决策层认知 × 组织复杂度：

| | 组织简单（单一工作流） | 组织中等（部门相对独立） | 组织复杂（多层级/央企） |
|---|---|---|---|
| 认知到位（A3–A4） | 快但天花板低 | **标杆最先冒出** | 慢但合同大 |
| 将信将疑（A2） | 教育成本高 | 值得培育 | 决策链太长 |
| 无意识（A1） | 跳过 | 跳过 | 跳过 |

认知到位比组织规模更要命：A3（有痛点、信 AI、不知怎么落地）咨询价值最直接，A4（见同行出结果才急）预算最容易批。中型组织通常最先冒出标杆案例，大型多层级反而拉慢节奏。

## 先过 PSF 三关

1. 痛点：是不是具体的人、具体任务、具体后果？
2. 经济性：节省、收入、风险或决策速度能否粗算？
3. 可行性：数据、权限、准确率门槛和组织条件是否支持？

三关都过，才进入更细的 FDE 机会评分。

## 十维评分

每项 0–3 分，总分 30。

| 维度 | 0 分 | 3 分 |
|---|---|---|
| Pain | 方向或口号 | 高频且有明确后果 |
| Frequency | 偶发 | 日/周持续发生 |
| Value | 无法估算 | 有 baseline 和价值口径 |
| Scope | 单人特例 | 多角色或同类客户共性 |
| Decision | 无人拍板 | 决策、预算、验收明确 |
| Data | 不给样本 | 真实样本可合规获得 |
| Integration | 无法接入 | 接口、权限、owner 明确 |
| Evaluation | “感觉更好” | 样本、指标、容错明确 |
| Economics | 只能覆盖人力 | 覆盖成本、风险和利润 |
| Reusability | 完全一次性 | 可沉淀规则/组件/评测 |

建议门槛：

- 24–30：Go，进入诊断与 SOW。
- 18–23：Hold，只做限时验证关键未知。
- 0–17：No-Go，给出条件路线图，不投入重交付。

## 五个高危信号

- 不允许接触真实使用者、流程或验收人。
- 要求先证明效果，但长期不提供真实或脱敏样本。
- 只有 IT 或采购对接，没有业务 owner。
- 第一次沟通就要求覆盖全公司所有场景。
- 责任全部给供应方，数据、接口和组织配合却无承诺。

## FDE 经济学速算

十维评分判断「值不值得做」，经济学速算判断「能不能赚钱」。粗算口径（仅作内部参考，非报价）：

- 人天成本 × 团队规模 × 周期 = 成本基线（如 3 人 × 半月 ≈ 5–6 万，仅覆盖成本）。
- 报价门槛：覆盖成本 + 风险 + 合理利润（粗略门槛 10 万+ 才有合理利润空间）。
- 优先级加权：能反哺垂类底座（沉淀连接器/评测集/Playbook 供第二单复用）的项目，即使单价低也加权。

算不清价值、或覆盖不了成本的机会，不要承诺结果。

## 最锋利的替代方案问题

在决定用 AI 前，依次问：

- 实习生、Excel、SOP、RPA 或现有工具能否更便宜地解决？
- AI 提供的是更低成本，还是过去做不到的新能力？
- 若只达到 90% 并由人复核，是否已经形成最优闭环？
