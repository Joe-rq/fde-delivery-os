# 来源与证据规则

知识库分别管理“来源类型”“主张状态”和“公开边界”。三者不可互相替代。

## 来源类型

| 代码 | 来源 | 用法 |
|---|---|---|
| P | 个人实践 | 用可审计材料支持局部结论；私有证据不直接公开 |
| O | 官方一手 | 用于职责、产品行为、公开规则和公开架构 |
| R | 研究或高质量开源 | 用于方法比较与工程参考 |
| C | 课程 | 只表示启发，不能自动当行业事实或可授权文本 |
| N | 社区/二手 | 用于发现线索，关键主张必须回源 |
| H | 假设 | 只用于规划 Discovery，不是事实来源 |

## 主张状态

| 状态 | 定义 |
|---|---|
| Confirmed | 当前公开材料可直接支持 |
| Private-evidence | 有私有材料，但因隐私或许可不能公开复核 |
| Inferred | 由证据合理推断，必须标明推断 |
| Hypothesis | 尚待授权数据或访谈验证 |
| Opinion | 作者、讲师或组织观点 |
| Disputed | 来源冲突或口径不同 |
| Stale | 可能已过期，需要重新核实 |

## 公开边界

1. 不公开真实姓名、客户身份、雇主内部信息、原始工单、内部链接或本地路径。
2. 不复制课程正文、讲义、原始作业或内部交付证据。
3. 合成沙盒必须显式写明“FDE 课程沙盒 PoC / 合成数据”。
4. 项目候选必须显式写明 `project-candidate / discovery-needed`。
5. 外部数字必须保留来源、样本、日期和适用边界。
6. 公开可访问不等于拥有复制、改编或再授权的权利。

## 数字与案例纪律

- 样本结果只支持该样本和该口径；
- Demo 或沙盒结果不外推到生产分布；
- 资产数量不解释为用户数、采用率或业务收益；
- 私有证据若未公开，只能标记 `Private-evidence`，不能写成可复现结论；
- 所有业务效果主张都需要独立的 baseline、观察期、归因边界和确认人。

## 许可决策

- `scripts/` 使用 MIT；
- Skills、文档、模板和案例受课程启发程度尚未逐项核清，当前不提供自由再利用许可；
- 外部来源保持各自许可，本仓库的链接或摘要不改变其权利归属；
- 发布前阻塞项见 [NOTICE](../NOTICE.md) 与 [公开发布说明](../07-Portfolio/公开发布说明.md)。
